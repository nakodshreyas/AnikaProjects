## 🏡 About the Project

**AnikaProjects** is a residential construction web application created to present construction services through a modern digital experience.

The project focuses on a clean interface, accessible navigation, and a professional presentation of residential construction services and project information.

## ✨ Highlights

- 🏠 **Construction-focused experience** — Present residential services and project information.
- 📱 **Responsive interface** — Designed to work across desktop, tablet, and mobile screens.
- 🎨 **Modern UI** — Clean layouts and a polished visual experience.
- 👥 **Client dashboard** — Project-related client functionality, where implemented.
- ⚙️ **Environment-based configuration** — Keep credentials outside the source code.
- 🚀 **Developer-friendly setup** — Run the application locally using npm.

## 🛠️ Tech Stack

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/nakodshreyas/AnikaProjects.git
```

### 2. Enter the project directory

```bash
cd AnikaProjects
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Review `.env.example` and configure the variables required by your application in your local environment file.

**Security note:** Never commit real API keys, database credentials, passwords, or service-role secrets to GitHub.

### 5. Start the development server

```bash
npm run dev
```

Open the local URL printed in your terminal.

## 🔐 Security

- Store private credentials in environment variables or a secrets manager.
- Keep `.env` and other files containing real secrets out of Git.
- Use server-side protection for privileged operations.
- Never expose Supabase service-role keys in frontend code.
- Apply appropriate authentication and database access policies.
